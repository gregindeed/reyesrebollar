# Brand Assets — Reyes Rebollar Properties LLC

Drop brand image files in this folder. They will be publicly accessible at:

  https://reyesrebollar.com/assets/brand/<filename>

## Expected files

| File | Usage |
|---|---|
| `rr-logo.png` | Main RR crown + lemon logo (transparent PNG, ~200px @2x) — used in email signatures |
| `rr-logo-dark.png` | Dark variant of the logo (if needed) |
| `rr-logo-horizontal.png` | Horizontal lockup variant (if any) |
| `wordmark.png` | Text-only wordmark (if any) |

## Email signature logo URL

Once you upload rr-logo.png, the email signature logo URL will be:

  https://reyesrebollar.com/assets/brand/rr-logo.png
